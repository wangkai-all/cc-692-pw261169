# 生产指标关联排查站

一个纯前端、零外部依赖的单页应用，用班次级**虚构**生产数据演示如何把"普通相关"与
"条件关联（偏相关 / 精度矩阵）"区分开，并贯穿数据质量、正则估计、留出模型选择、
稳定性诊断的完整链路。**所有关联图均非因果图。**

## 运行

```bash
# 方式一：直接用浏览器打开 index.html（file:// 即可，无外部请求）
# 方式二：本地静态服务
node tests/serve.js        # http://localhost:8123/

# 测试（Node >= 18，无需安装任何依赖）
npm test                   # 统计核心 55 项 + 端到端 UI（DOM 垫片）32 项
```

## 数据（`src/data.js`，确定性随机，可复现）

- 90 个班次、12 个指标（负载、炉温、排气温度、电机电流、能耗、燃气、原料、冷却压力、
  振动、缺陷率、环境温度、计划产量）、12 个生产批次、4 种工况。
- 生成结构是一个**共同原因网络**：负载率直接驱动炉温、燃气、原料、振动、缺陷率等，
  另含少量真实直接边（如负载→排气温度在控制炉温后仍存在），用于教学对照。
- 故意植入三类"数据事故"：
  - **缺失**：约 3.5% 的指标单元为 MCAR 缺失，另有 3 个班次多列缺失；
  - **恒定列**：`target_qty` 整表恒定；`ambient_temp_c` 在调试批次 B12 内恒定；
  - **完全/仿射相同列**：`motor_current_a` 由负载率仿射复制（|r|≈1）。
- **n<p 工况**：调试批次 B12 只有 3 个完整班次，指标数多于样本数。

## 统计链路（`src/stats.js`，手写实现，无 numpy/sklearn）

1. **同一批完整记录（listwise）**：含任一保留指标缺失的班次整行排除，所有协方差元素
   都来自这同一批 n 条记录。**绝不逐对删缺失后拼接**——`pairwiseDiagnostics` 会专门构造
   逐对矩阵并展示其最小特征值可能为负（高工况下可观察到非正定），证明它不是合法协方差。
2. **恒定列 / 重复列独立处理**：方差为 0 的列、|r|>1−1e-5 的仿射等价列在估计前剔除并公示。
3. **MLE 与正则**：n≤p 时 MLE 精度矩阵不存在（求逆返回 `null`）。提供
   - Ledoit–Wolf(2004) / OAS(2010) 收缩协方差（闭式，含严格 π̂ 估计）；
   - graphical lasso（FHT 2008 坐标下降）求稀疏精度矩阵，精确零元素即条件独立约束。
4. **按生产批次留出选择正则力度**：以整批班次为折单位（单批次工况退化为留一班次 LOO），
   在留出批次上最小化测试负对数似然。glasso 同时给出 NLL 最优点与 **1-SE 稀疏解**
   （与最优 NLL 相差不超过 1 个标准误时取最大 λ，预测精度相当但更稀疏稳定），默认采用后者，可切换。
5. **偏相关**：由精度矩阵 Θ 得 `−Θᵢⱼ/√(ΘᵢᵢΘⱼⱼ)`，即控制其余 p−2 个变量后的线性联系。
6. **稳定性**：40 次 bootstrap 的边出现率、符号一致率、10–90% 分位；逐批次留一（jackknife）区间。

## 页面交互（`src/ui.js` + `src/charts.js`）

- 顶部统一过滤行：**切换工况/方案会重跑整条链路**（预处理→估计→CV→稳定性→全部视图）。
- ① 数据质量：完整记录数、被排除班次及原因、恒定/重复列处理、逐对删缺失的非法性诊断。
- ② 估计：MLE 病态/奇异性、当前拟合参数与来源、按批次留出 CV 曲线（标注最优点与 1-SE 点）。
- ③ 普通相关矩阵 vs 偏相关矩阵（均有热力图与表格视图，蓝-红发散色）。
- ④ 网络图 + **边诊断**：点任意边/热力格/表格行，查看控制了哪些变量、普通相关与偏相关
  的差值与衰减、bootstrap 与留批次稳定性、生成模型对照（仅教学）。
- ⑤ 全指标对明细表；⑥ 共同驱动反例的联动教学表。
- 明暗双主题；颜色取自经 `validate_palette.js` 校验的设计令牌。

## 边界情形的处理对照

| 情形 | 处理 |
|---|---|
| 样本比指标少（n<p） | MLE 求逆为 null → 强制走收缩/glasso；CV 退化 LOO；UI 显著预警 |
| 某列恒定 | 估计前剔除并在数据质量区公示值与原因 |
| 两列完全相同/仿射等价 | 保留其一、剔除另一，公示关系（\|r\|≈1） |
| 逐对删缺失 | 不用于估计；单独计算并展示其非正定/样本数不一致，作为反例 |
| 换样本不稳定 | bootstrap 出现率/符号率 + 留批次区间，在边诊断与明细表中呈现 |
